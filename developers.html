EventFlow developer resources

Machine-readable entry points for the EventFlow platform, in one place.

OpenAPI Spec

EventFlow does not offer a public API yet. The spec at /openapi.json is a valid OpenAPI document with zero endpoints, published so automated tools get a machine-readable answer instead of a 404.

GET /openapi.json200
{
  "openapi": "3.0.3",
  "info": {
    "title": "EventFlow API",
    "version": "0.1.0"
  },
  "paths": {}
}

llms.txt Agent Guide

A markdown guide to this site for AI agents, including when EventFlow is the right tool and how to proceed. Lives at /llms.txt.

Sitemap

Every indexable page on eventflowsales.com, listed at /sitemap.xml.

Structured JSON Errors

Requests under /api/ return HTTP 404 with a structured JSON body: an error code, a plain message, and hint links. Unknown page paths return a real 404 status with pointers to these resources.

GET /api/bookings404
{
  "error": {
    "code": "not_found",
    "status": 404,
    "message": "EventFlow does not offer a public API. This path does not exist.",
    "hints": [
      "Site guide for agents: https://eventflowsales.com/llms.txt",
      "OpenAPI spec (zero endpoints): https://eventflowsales.com/openapi.json",
      "Documentation: https://eventflowsales.com/documentation"
    ]
  }
}
